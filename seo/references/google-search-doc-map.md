## Routing shortcuts

- New site or page: Essentials + Starter Guide + sitemaps + links + Search Console.
- AI/GEO question: AI optimization guide + helpful content + Search Essentials + page type docs.
- Content quality audit: helpful content + spam policies + Starter Guide + relevant appearance docs.
- Indexing issue: Essentials technical requirements + robots meta/noindex + robots.txt + canonicalization + URL Inspection/Search Console.
- Duplicate pages: canonicalization overview + consolidate duplicate URLs + redirects + sitemap hygiene.
- JS site: JavaScript SEO basics + fix JS problems + lazy loading + URL Inspection rendered HTML.
- Rich results: structured data intro + general guidelines + exact feature guide + Rich Results Test.
- Traffic drop: debug traffic drops + Search Console + ranking updates + technical incident checks + content quality checks.
- Ecommerce: ecommerce overview + product structured data + merchant listings + URL/site structure + pagination.
- International: international overview + hreflang/localized versions + locale-adaptive crawling.
