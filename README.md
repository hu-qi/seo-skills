# SEO Skill

Google Search Central grounded ChatGPT Skill for SEO, GEO/AEO, technical SEO, content quality review, Search Console diagnosis, structured data, ecommerce SEO, international SEO, and Google Search appearance guidance.

## Files

- `seo/SKILL.md` - main skill instructions.
- `seo/references/google-search-doc-map.md` - Google Search Central documentation map and routing guide.
- `seo/references/checklists.md` - reusable SEO, GEO, technical, content, and traffic-drop checklists.
- `seo/agents/openai.yaml` - ChatGPT skill metadata.

## Source basis

This skill is designed around the Google Search Central documentation set at <https://developers.google.com/search/docs>, including SEO fundamentals, crawling and indexing, ranking and search appearance, structured data, monitoring/debugging, and specialty guides.
